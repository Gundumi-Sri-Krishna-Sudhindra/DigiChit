# Chit Lifecycle and State Machine

This document specifies the lifecycle stages of chit groups within DigiChit.

## States
1. **Draft / Initiated**: Group configuration and slot allocation.
2. **Active / In-Progress**: Periodic cycles running auctions and collection.
3. **Bidding Active**: Live auction room open for bid submissions.
4. **Cycle Completed**: Winner recorded, prize money allocated, dividends credited.
5. **Terminated / Closed**: All installments collected and distributed.

### Clarification on Cycles vs Months
Each cycle corresponds to one bidding period and installment collection window.
