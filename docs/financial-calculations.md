# Financial Formulas & Dividend Distribution

Specification of chit fund mathematical formulations.

## Key Formulas
- `Pot Value = Monthly Contribution * Total Members`
- `Discount = Highest Bid Amount`
- `Foreman Commission = Pot Value * Commission Percentage`
- `Net Dividend Pool = Discount - Foreman Commission`
- `Dividend Per Member = Net Dividend Pool / Total Members`
- `Next Installment = Monthly Contribution - Dividend Per Member`

### Statutory Ceilings
Commission percentage is regulated per local Chit Funds Act guidelines (maximum 5% typically).
