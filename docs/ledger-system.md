# Double-Entry Ledger System

The DigiChit ledger enforces financial integrity by recording balanced debit and credit entries for all movements.

## Core Ledger Accounts
- **Cash / Bank Account**: Tracks inflows from member contributions and outflows for payouts.
- **Member Dues Receivable**: Tracks pending dues from members for each cycle.
- **Prize Money Payable**: Holds allocated prize money before disbursal to winners.
- **Foreman Commission**: Records organizer fees deducted per cycle rules.
- **Dividend Pool**: Records dividend discounts distributed among participating non-winning members.
