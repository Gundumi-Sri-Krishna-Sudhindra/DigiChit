# Release Management & Versioning

Guidelines for version tagging and release cadence.

## SemVer Rules
- **MAJOR**: Breaking schema changes or API deprecations.
- **MINOR**: Backward-compatible new features and UI additions.
- **PATCH**: Bug fixes, documentation updates, and performance tuning.

### Release Checklist
Ensure version bump in `package.json` for both client and server packages prior to tagging.
