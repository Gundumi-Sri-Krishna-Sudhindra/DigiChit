# DigiChit Architecture Overview

DigiChit is a full-stack digital chit fund management application built with a Node.js/TypeScript backend and a React/TypeScript frontend.

## System Components
- **API Server**: Express.js server handling core business logic, authentication, and RESTful APIs.
- **Client**: Single-page application built with React, Vite, and TailwindCSS.
- **Auction Engine**: Real-time websocket-driven live bidding room.
- **Ledger System**: Double-entry ledger tracking all transactions, dividends, and foreman commissions.
