# Automated Testing Strategy

Overview of testing frameworks and execution tiers across DigiChit.

## Test Tiers
1. **Unit Tests**: Domain logic, financial calculation math, ledger rules.
2. **Integration Tests**: API routes, MongoDB repository adapters, JWT auth.
3. **End-to-End Tests**: Auction lifecycle and live bidding simulations.

### Running Tests
Run `npm test` inside server or client directories respectively.
